# PPP | DTF 출력, 프레스 임가공, 완성티, 갱시트 빌더

대구 직영 DTF 공장 PPP의 홈페이지입니다. 서버 없이 GitHub Pages에서 바로 돕니다.

## 페이지

- `index.html` — 카테고리 탭으로 나뉜 한 페이지 사이트. 해시 라우팅으로 화면을 전환합니다.
  - `#home` 홈: 히어로, 4대 서비스 카드, 갱시트 빌더 바로가기, 스페셜 미리보기, 대표 견적
  - `#film` DTF 필름: 60cm 풀폭 특징, 화이트 잉크 기준, 1m/5m/10m 단가, 출고 흐름
  - `#press` 프레스 임가공·완성티: 5장부터 임가공, 10장부터 완성티, 원단별 온도 처방
  - `#special` 180cm 승화·스페셜: 180cm 광폭 승화, 3D·렌티큘러, 천연염료, 봉제
  - `#quote` 실시간 견적·FAQ: 단가 계산기, 단가표, 파일 규격, FAQ 11개
  - `builder.html`: 60cm × 1m 갱시트 빌더
  - 예전 앵커(`#price`, `#files`, `#faq`, `#garment`, `#tee`, `#lineup` 등)는 알맞은 카테고리로 연결됩니다.
- `builder.html` — 60cm × 1m 갱시트 빌더. 도안 업로드, 크기 프리셋, 자동 배치, 300dpi 출력 파일 생성.
  - 한 장으로 담기 어려운 길이는 실제 적용 해상도를 표시하고, 1m 단위(기기 한도에 따라 더 짧게) 타일로 나눠 300dpi ZIP을 만듭니다.
- `assets/site.css`, `assets/site.js` — 사이트 본문 스타일과 탭 라우팅, 견적 계산기
- `assets/order.css`, `assets/order.js` — 두 페이지가 함께 쓰는 주문서 모달과 플로팅 상담 바
- `assets/fonts.css` — Pretendard(본문), Space Grotesk(영문·숫자), Instrument Serif(포인트)
- `robots.txt`, `sitemap.xml` — 검색엔진 수집용

## 주문 흐름

서버와 결제 대행을 두지 않습니다. 주문서 모달에서 이름, 연락처, 배송지를 적고 **개인정보 수집 및 이용에 동의**하면 주문번호(`PPP-YYMMDD-XXXX`)와 주문 내역을 클립보드에 복사하고 카카오톡 채널로 넘깁니다. 입금 계좌는 상담에서 안내합니다.

## 금액 기준

모든 금액은 부가세 포함입니다. 필름 배송비 5,000원은 별도이고, 계산기의 정적 기본값(1m 9,000원 + 배송 5,000원 = 14,000원)은 스크립트 계산 결과와 같습니다.
